# Culturae Dashboard

Admin dashboard for the Culturae platform.

## Stack

- **React 19** + **TypeScript 5**
- **Vite 6** (SWC)
- **Material UI 6** + Fluent UI Icons
- **React Router 7**
- **Recharts** — charts & analytics
- **i18next** — i18n
- **React Hook Form** + **Zod** — form validation
- **notistack** — toast notifications
